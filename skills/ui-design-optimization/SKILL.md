# UI界面优化 — 35条设计法则

## 使用指南

当用户讨论以下话题时，读取 `references/ui-design-tips.md` 获取完整的设计法则：

- UI/UX 设计优化建议
- 界面排版、配色、布局调整
- 前端组件视觉改进
- 产品设计评审
- 设计稿优化反馈
- 任何涉及"怎么让界面更好看/更好用"的问题

**工作流：**
1. 读取 `references/ui-design-tips.md` 获取35条法则的完整内容。
2. 根据用户的具体场景，筛选最相关的法则。
3. 给出具体、可操作的设计优化建议，引用对应的法则编号。
4. 如需要，使用 `show_widget` 工具渲染对比示例。

## 核心设计原则

> **留白、对齐、对比、一致性、层级清晰、以用户为中心。**

所有建议均遵循"错误示例 vs 正确示例"的对比逻辑。在给出建议时，应明确指出当前设计违反了哪条法则，以及优化后的预期效果。
